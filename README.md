One funny line — a single sentence of at most 200 characters — for make.fun's "The One-Line Laugh" bounty. The program writes the line to `/output/entry.txt`, where the house judge reads it two at a time and keeps the bigger laugh.

The line: *My bank flagged my account for unusual activity — it was me buying groceries instead of takeout.*

## Run it

```sh
python3 main.py
```
